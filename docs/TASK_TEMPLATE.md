# Plantilla para una tarea

## Objetivo

¿Qué problema o historia se quiere resolver?

## Fuentes y contexto

Enlaces a la historia, requisito, decisión vigente y archivos relevantes.

## Alcance

Qué incluye la tarea y qué no debe cambiar.

## Restricciones y dependencias

Reglas de la cátedra, acuerdos técnicos, datos o tareas previas necesarias.

## Criterios de aceptación

Condiciones observables para considerar terminado el trabajo.

## Verificación realizada

Comprobaciones ejecutadas y resultados reales. Si no se verificó, indicarlo.

## Cierre

Cambios realizados, decisiones aprobadas, pendientes y documentos de contexto actualizados.
