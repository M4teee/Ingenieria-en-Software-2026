# Instrucciones para Claude

- Leé `AGENTS.md` y usá `docs/INDEX.md` para encontrar solo el contexto pertinente.
- Consultá las fuentes portables de `docs/context/` indicadas en `docs/SOURCE_INDEX.md`; la exportación de Taiga es una derivación sanitizada, no una conexión al tablero actual.
- Declarà qué archivos y rama/revisión recibiste. La sincronización del repo puede no incluir Issues, PRs, historial ni cambios locales.
- No afirmes que inspeccionaste el árbol local ni que ejecutaste comandos si solo recibiste archivos sincronizados.
- Separá hechos, decisiones aprobadas, propuestas e incertidumbres; la fuente original prevalece sobre sus resúmenes.
- Inspeccioná el código y el diff actuales antes de actualizar documentos. Seguí `docs/DOCUMENTATION_WORKFLOW.md` después de `git pull` y antes de preparar un `git push`; cambiá solo los documentos afectados.
- No marques historias o funcionalidades como completas por aparecer en una planificación. Informá qué verificaste y qué queda sin comprobar.
- No compartas ni reproduzcas datos privados o material restringido. Confirmá autorización antes de enviar archivos a una IA.
- Para revisar código, pedí o usá el Issue vigente, criterios de aceptación y diff exacto.
